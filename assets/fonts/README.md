# Inter

Static Regular (400) and Bold (700) font files from Expo Google Fonts:

- https://github.com/expo/google-fonts/tree/main/font-packages/inter/400Regular
- https://github.com/expo/google-fonts/tree/main/font-packages/inter/700Bold

The files are bundled locally and loaded with the existing `expo-font` package.
No font package was installed. Keep `OFL.txt` alongside the files when distributing them.
